# Paradise Nursery

Paradise Nursery is a front-end shopping application for houseplants, built with React and Redux Toolkit.

## Features
- Landing page with company name, description and a Get Started button
- Product listing page with 18 houseplants in 3 categories (Air Purifying, Aromatic, Low Light)
- Add to Cart button that disables once a plant is in the cart
- Header with Home / Plants / Cart navigation and a live cart item count
- Shopping cart page with thumbnails, unit prices, per-plant totals, increase / decrease / delete buttons, overall total, Continue Shopping and Checkout ("Coming Soon")

## Run locally
```
npm install
npm run dev
```

## Deploy to GitHub Pages
```
npm run build
npm run deploy
```
